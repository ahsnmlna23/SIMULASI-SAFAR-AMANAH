# Simulasi Pembiayaan Safar Amanah

Website simulasi pembiayaan umrah syariah (akad murabahah) untuk tim sales Safar Amanah.
Dibuka di browser HP atau laptop, tanpa login.

- 5 program: Berangkat ≤45 Hari, Berangkat 3 Bulan, Berangkat 6 Bulan, B2B / Rombongan, Tabungan Umrah
- DP mulai dari minimum sesuai syarat program dan tidak bisa di bawahnya; tenor 24 bulan
- Jadwal pembayaran, pilihan DP, pencocokan dengan kemampuan klien, salin ringkasan ke WhatsApp

Angka pada website ini adalah simulasi. Nilai final mengikuti akad setelah analisa kelayakan.
